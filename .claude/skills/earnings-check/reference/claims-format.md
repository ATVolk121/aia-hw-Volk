# แบบฟอร์ม claims.csv — คำพูดผู้บริหาร 1 แถว = 1 คำกล่าวที่ตรวจได้

ไฟล์ CSV (UTF-8) หัวตารางตามลำดับนี้ ห้ามเปลี่ยนชื่อคอลัมน์:

```
id,source,loc,quote,metric,period,kind,compare,claimed,unit,approx,comparator,direction,basis,check_by,due,note
```

| คอลัมน์ | ใส่อะไร | ตัวอย่าง |
|---|---|---|
| `id` | รหัสเรียงลำดับ | `O01` (จาก Oppday) · `M01` (จาก MD&A) |
| `source` | `oppday` หรือ `mda` | `oppday` |
| `loc` | ตำแหน่งให้เปิดตามได้: Oppday = เวลาของย่อหน้า (`m:ss`) · MD&A = `หน้า N` จากเครื่องหมาย `[[หน้า N]]` | `3:50` · `หน้า 2` |
| `quote` | ข้อความ **ตามต้นฉบับ** ไม่เกิน 200 ตัวอักษร ห้ามแก้คำผิดของเสียงถอดอัตโนมัติ | `รายได้รวมในไตรมาส 2 ก็เอ่อปิดอยู่ที่ประมาณ 265,700 ล้านบาท` |
| `metric` | ชื่อตัวเลขจากรายการด้านล่าง · ไม่มีในรายการใช้ `other` | `total_revenue` |
| `period` | งวดที่พูดถึง: `3M` (ไตรมาส) · `6M` · `9M` · `12M` · `BS` (ยอด ณ สิ้นงวด) · `FY` (ทั้งปี ใช้กับเป้า) | `3M` |
| `kind` | ชนิดคำกล่าว (ดูตารางถัดไป) | `level` |
| `compare` | ฐานเทียบของ growth/margin_chg/direction: `yoy` (เทียบปีก่อน) · `qoq` (เทียบไตรมาสก่อน) · ว่าง | `yoy` |
| `claimed` | ตัวเลขที่พูด (ตัวเลขล้วน ไม่มีลูกน้ำ) · หน่วยเงินแปลงเป็น **ล้านบาท** เสมอ · bps แปลงเป็นจุด (60 bps = 0.6) | `265700` |
| `unit` | `ล้านบาท` · `%` · `จุด` · `บาท` · `วัน` · `เท่า` · `สาขา` · `อื่น` | `ล้านบาท` |
| `approx` | `y` ถ้ามีคำว่า ประมาณ / เกือบ / ราว / กว่า / around / about · ไม่มี = `n` | `y` |
| `comparator` | `=` ปกติ · `>` ("กว่า", "เกิน") · `<` ("ไม่ถึง", "ต่ำกว่า") | `=` |
| `direction` | `up` · `down` · `flat` (ใช้กับ kind=direction และใส่กำกับได้ทุกแถวที่พูดทิศทาง) | `up` |
| `basis` | `consolidated` (งบรวม) · `separate` (งบเดี่ยว/เฉพาะกิจการ) · `unspecified` (ไม่ได้บอก) | `consolidated` |
| `check_by` | ใช้กับ kind=qualitative: นิพจน์ทดสอบด้วยตัวเลข (ดูด้านล่าง) | `sga_yoy < revenue_yoy` |
| `due` | ใช้กับ kind=guidance: วันที่ต้องกลับมาตรวจ (YYYY-MM-DD) | `2027-02-28` |
| `note` | หมายเหตุ เช่น เสียงถอดซ้ำตัวเลข | `ASR ซ้ำ "3.6% 6%" ใช้ 3.6` |

## kind — ชนิดคำกล่าว

| kind | ความหมาย | claimed คืออะไร |
|---|---|---|
| `level` | ยอด ณ งวดนั้น | ยอด เช่น 7512 (ล้านบาท) · 0.83 (บาท) · 16284 (สาขา) |
| `growth` | โต/ลดกี่ % | % การเปลี่ยนแปลง (ลดให้ใส่ค่าลบ) |
| `margin` | อัตรากำไร/สัดส่วนเป็น % | % เช่น 22.8 |
| `margin_chg` | อัตรากำไรเปลี่ยนกี่จุด | จุด (ลดให้ใส่ค่าลบ) |
| `direction` | บอกแค่ทิศทาง ไม่มีตัวเลข ("เพิ่มขึ้น", "ลดลง", "ทรงตัว") | ว่าง · ใส่ `direction` |
| `guidance` | เป้า แผน คาดการณ์อนาคต | ตัวเลขเป้า (ถ้ามี) · ใส่ `due` |
| `qualitative` | คำบรรยายเชิงคุณภาพที่ทดสอบด้วยตัวเลขได้ ("คุมค่าใช้จ่ายได้ดี") | ว่าง · ใส่ `check_by` |

## metric — ชื่อตัวเลขที่ระบบรู้จัก

| metric | คือ | หน่วยปกติ |
|---|---|---|
| `revenue` | รายได้จากการขายและบริการ (ไม่รวมรายได้อื่น) | ล้านบาท |
| `total_revenue` | รายได้รวมตามงบ | ล้านบาท |
| `gross_profit` · `gross_margin` | กำไรขั้นต้น · อัตรากำไรขั้นต้น | ล้านบาท · % |
| `sga` · `sga_to_rev` | ค่าใช้จ่ายขาย+บริหาร · สัดส่วนต่อรายได้ | ล้านบาท · % |
| `selling_exp` · `admin_exp` | ค่าใช้จ่ายขาย · ค่าใช้จ่ายบริหาร | ล้านบาท |
| `operating_profit` · `ebit` · `op_margin` | กำไรจากการดำเนินงาน · กำไรก่อนดอกเบี้ยและภาษี · อัตรากำไรจากการดำเนินงาน | ล้านบาท · % |
| `net_profit` · `net_margin` | กำไรส่วนของบริษัทใหญ่ · อัตรากำไรสุทธิ | ล้านบาท · % |
| `eps_basic` | กำไรต่อหุ้น | บาท |
| `other_income` · `fx_gain` · `finance_cost` · `share_assoc` | รายได้อื่น · กำไรค่าเงิน · ต้นทุนทางการเงิน · ส่วนแบ่งกำไรบริษัทร่วม | ล้านบาท |
| `inventories` · `trade_receivables` · `trade_payables` · `cash` | สินค้าคงเหลือ · ลูกหนี้ · เจ้าหนี้ · เงินสด (ยอด ณ สิ้นงวด) | ล้านบาท |
| `inventory_days` · `receivable_days` · `payable_days` · `ccc` | วันสินค้าคงเหลือ · วันลูกหนี้ · วันเจ้าหนี้ · วงจรเงินสด | วัน |
| `ocf` · `ocf_to_np` · `capex` · `dividends_paid` | เงินสดจากการดำเนินงาน · เทียบกำไร · ลงทุน · ปันผลจ่าย | ล้านบาท · เท่า |
| `net_debt` · `de_ratio` · `st_debt` | หนี้สุทธิ · หนี้สินต่อทุน · เงินกู้ระยะสั้น | ล้านบาท · เท่า |
| `other` | อื่น ๆ ที่งบไม่มี (จำนวนสาขา ส่วนแบ่งตลาด ยอดขายต่อสาขา ฯลฯ) → ระบบให้ ⬜ ตรวจไม่ได้ | — |

## check_by — นิพจน์สำหรับคำกล่าวเชิงคุณภาพ

ใช้ชื่อ metric ต่อท้ายด้วย `_yoy` (% หรือจุดที่เปลี่ยนจากปีก่อน) · `_qoq` (จากไตรมาสก่อน) · ไม่มีต่อท้าย = ค่างวดนี้
ตัวดำเนินการ `<` `>` `<=` `>=` เชื่อมหลายเงื่อนไขด้วย `and`

| คำพูด | check_by |
|---|---|
| "คุมค่าใช้จ่ายได้ดี" | `sga_yoy < revenue_yoy` |
| "อัตรากำไรขั้นต้นดีขึ้น" | `gross_margin_yoy > 0` |
| "บริหารสต็อกได้ดี" | `inventory_days_yoy < 0` (ถ้ามีปีก่อน) หรือ `inventories_qoq < revenue_qoq` |
| "กำไรมาจากธุรกิจหลัก" | `fx_share_pbt < 20 and other_income_share_pbt < 20` |
| "กระแสเงินสดแข็งแกร่ง" | `ocf > 0 and ocf_to_np > 0.8` |

## กติกา

- เก็บเฉพาะคำกล่าวเกี่ยวกับ **ผลประกอบการของบริษัท** (ไม่เก็บภาวะเศรษฐกิจทั่วไป)
- ตัวเลขจากเทปเป็นเสียงถอดอัตโนมัติ — คัดลอกตามที่ได้ยิน ถ้าเห็นชัดว่าซ้ำ (เช่น "5.3% 3%") ให้เลือกค่าที่สมเหตุสมผลที่สุดแล้วจดใน `note`
- แยกให้ออกว่าพูดถึง **งบเดี่ยว** หรือ **งบรวม** (ผู้บริหารหลายบริษัทเปิดด้วยงบเดี่ยวที่ตัวเลขสวยกว่า)
- ไม่ตัดสินผลเอง — แค่บันทึกคำพูด การตัดสินเป็นงานของ `match_claims.py` และ agent ตรวจ
