# /earnings-check — ผู้บริหารพูด vs งบจริง

ทำให้หุ้น 1 ตัวหรือหลายตัว 3 อย่างตามโจทย์กลุ่ม "อ่านงบ / Oppday / Earnings":
1. **อ่านเอง** — สรุปงบ ทุกตัวเลขชี้ถึงไฟล์ · ชีต · เซลล์
2. **ดึงอัตโนมัติ** — งบ (ก.ล.ต. iDisc) · MD&A · คำบรรยายคลิป Oppday (ช่อง SET Thailand)
3. **ตรวจคำพูด** — ทุกคำกล่าวของผู้บริหารได้ผล ✅ ตรง · 🟡 ตรงแต่เลือกพูด/ต่างฐาน · ❌ ไม่ตรง · ⬜ ตรวจไม่ได้ · 🔭 สัญญาอนาคต
   และรายการ "สิ่งที่ไม่ได้พูด" (ตัวเลขที่แย่ลงชัดแต่ไม่มีใครพูดถึง)

สคริปต์อยู่ที่ `${CLAUDE_SKILL_DIR}/scripts/` (Python + ไลบรารีมาตรฐาน + PyMuPDF) · แบบฟอร์มคำพูดที่ `${CLAUDE_SKILL_DIR}/reference/claims-format.md`
ทีม agent: `kep-lek` (เก็บเลข · sonnet) และ `check-jing` (ตรวจจริง · Opus) ใน `.claude/agents/`

## กฎที่ไม่ผ่อน
- ตัวเลขเข้ารายงานได้ทางเดียวคือผ่าน FACTS.csv (จากงบที่บริษัทยื่น) · ตัวเลขที่คิดเองกำกับ `[คำนวณ]`
- คำบรรยายคลิปเป็นเสียงถอดอัตโนมัติ ใช้เป็น "สิ่งที่พูด" เท่านั้น ห้ามใช้แทนตัวเลขงบ
- ไม่มีเอกสารต้นฉบับ = ไม่เขียน · หาไม่ได้ให้บอกตรง ๆ ว่า "ต้องโหลดเอง"
- คลังหุ้น `C:\ทุกบริษัท\<TICKER>\` (Mac `~/ทุกบริษัท/`): ชั้นบน = เอกสารทางการ ห้ามแก้ ห้ามลบ ห้ามเขียนทับ · งานของ AI ไว้ใน `_reference\`
- ไม่แนะนำซื้อขาย ไม่มีราคาเป้า ท้ายรายงานเป็น "ต้องเชื่ออะไร + เงื่อนไขเปลี่ยนใจ"
- ticker กำกวมหรือชื่อบริษัทจาก iDisc ไม่ตรงที่ตั้งใจ → หยุดถามก่อน

## ขั้นตอน (หุ้นหลายตัวให้ทำขั้น 1–5 ขนานกันได้)

ตั้งตัวแปรในใจ: `T` = ticker · `P` = งวด (ไม่ระบุ = ไตรมาสล่าสุดที่มีงบ) · `V` = `C:\ทุกบริษัท\T` · `W` = `V\_reference\earnings-check-P`
และ `S` = `${CLAUDE_SKILL_DIR}/scripts`

### 0. เช็กเครื่อง (ครั้งแรกของ session)
- `python -c "import pymupdf"` ต้องผ่าน
- `python -m yt_dlp --version` — ไม่มี → **ถามผู้ใช้ก่อน** แล้วติดตั้ง `python -m pip install --user yt-dlp` (ไม่ยอม = ข้ามเทป ใช้ MD&A อย่างเดียว)
- หา `fetch_th.py` ของปลั๊กอิน stock-deepdive-lite: `~/.claude/plugins/cache/boonchu-tools/stock-deepdive-lite/*/bin/fetch_th.py`
  ไม่มี → ใช้งบที่มีในคลัง หรือทำรายการ "ต้องโหลดเอง" ตามลิงก์ใน `.claude/commands/new-stock.md`

### 1. คลังหุ้น + เอกสาร (ดึงเฉพาะที่ขาด ไม่ทับของเดิม)
1. ดู `V` ว่ามีงบ `*_FS_P*.xlsx` · งบไตรมาสก่อน · **งบงวดเดียวกันปีก่อน** (เช่น Q2-2568 สำหรับ Q2-2569 — ธุรกิจสินเชื่อต้องใช้คิดพอร์ตโต YoY และ yield ปีก่อน) · `*_MDA_P*` · `*_Oppday_P*.md` · `*_56-1_*.txt` (ใช้ตรวจผู้บริหาร)
2. ขาดงบ → `python fetch_th.py T --out <scratchpad>/fetch/T --periods 5` แล้ว
   `python "$S/vault_intake.py" <scratchpad>/fetch/T --ticker T` (สร้างโฟลเดอร์ + `_analysis` + `_reference` ตั้งชื่อตามกติกา ย้ายเข้าคลัง) — ตรวจบรรทัด "งวด ... (จากหัวคอลัมน์งบ)" ทุกบรรทัด ถ้าเป็น "เดาจากเดือนที่ยื่น" ให้เปิดไฟล์ยืนยัน
3. ขาด MD&A → `python "$S/fetch_mda.py" T --period P --out V` (ตรวจชื่อบริษัทที่พิมพ์ออกมา)
4. ขาดเทป → `python "$S/fetch_oppday.py" T --period P --out V` · ไม่เจอคลิป = ใช้ MD&A อย่างเดียวและเขียนบอกในรายงาน
5. หุ้นใหม่: เพิ่มแถวใน `C:\ทุกบริษัท\notebooks-index.md` (NotebookLM ไม่ได้เชื่อม = เขียนว่า "ยังไม่ได้เชื่อม")
6. MD&A เดิมที่ไม่มีเครื่องหมาย `[[หน้า N]]` → สร้างฉบับมีเลขหน้าไว้ใน `W` (ห้ามเขียนทับ .txt เดิม)
7. ไฟล์ Word รุ่นเก่า (.doc หมายเหตุงบ/รายงานผู้สอบ) → `powershell -File "$S/doc_to_txt.ps1" "V"` (Windows ที่มี Word · ได้ .txt คู่ ไม่แตะต้นฉบับ)
8. ไม่มีคลิปบนช่อง SET แต่มีวิดีโอในเครื่อง → ถอดเสียงในเครื่อง (faster-whisper) ได้บทถอด `.md` มีเวลา แบบเดียวกับเทป Oppday

### 2. FACTS — ตัวเลขจากงบ
```
python "$S/fs_facts.py" V/*_FS_<ไตรมาสก่อน>*.xlsx V/*_FS_P*.xlsx --ticker T --out W/FACTS.csv
```
- ดูบรรทัด "หาไม่เจอ:" ถ้าบรรทัดหลักหาย (รายได้ ต้นทุน กำไร สินค้าคงเหลือ ลูกหนี้ เงินสดจากการดำเนินงาน) เปิด `V/*_FS_P.txt` หาเอง
  แล้วเพิ่มแถวใน FACTS.csv ให้ครบทุกคอลัมน์ (ไฟล์ · ชีต · เซลล์) · ไม่เจอจริงให้ปล่อยว่าง ห้ามเดา
- ดู `label_raw` ของรายได้ กำไร และเงินสดจากการดำเนินงานว่าจับถูกบรรทัด
- ใส่งบงวดเดียวกันปีก่อนเข้าไปด้วย (`V/*_FS_<Qx>-<ปีก่อน>*.xlsx`) สคริปต์จะใช้คิด YoY ของยอดงบดุล
- **กลุ่มธุรกิจ**: อ่าน `reference/sectors/<กลุ่ม>.md` ก่อนเขียนบทสรุป (มี `nonbank.md` · `it-distribution.md` · `management.md` ใช้ทุกกลุ่ม)
- **ธุรกิจสินเชื่อ (Non-bank)**: ตัวเลข Stage 1/2/3 · POCI · ค่าเผื่อหนี้สงสัยจะสูญ อยู่ในหมายเหตุ ไม่อยู่ใน xlsx
  → ให้ agent (sonnet) อ่าน `V/*_FS_P*_Notes.txt` ลง `W/notes_facts.csv` (หัวตารางเดียวกับ FACTS + `for_file` = ชื่อไฟล์งบหลัก · `cell` = "บรรทัด N" ของ .txt)
  แล้ว `python "$S/merge_notes.py" W` (รันซ้ำได้ แทนแถวเดิม) · gross loans = Stage รวม ใช้คิด NPL · Stage 2 · Coverage

### 3. คำพูดผู้บริหาร — ส่ง agent `kep-lek` (หุ้นละ 1 ตัว ขนานกัน)
ส่ง: ticker · งวด · path เทป · path MD&A (มีเลขหน้า) · path `W/claims.csv` · path แบบฟอร์ม `claims-format.md`
(ถ้า agent ชื่อ kep-lek ไม่ขึ้นในรายการ ใช้ general-purpose ระบุ `model: sonnet` แล้วให้อ่าน `.claude/agents/kep-lek.md` เป็นคำสั่ง)

### 4. เทียบกับงบ
```
python "$S/match_claims.py" --facts W/FACTS.csv --claims W/claims.csv --period P --vault V --out W/claims_checked.csv
```
ได้ `claims_checked.csv` + `unsaid.csv` อ่านรายการ ❌/🟡 ที่พิมพ์ออกมา

### 5. ด่านตรวจ — ส่ง agent `check-jing` (หุ้นละ 1 ตัว)
ส่ง: `W/claims_checked.csv` · `W/unsaid.csv` · `W/FACTS.csv` · `V` · ปลายทาง `W/verify.csv`
- ผล `fix`/`drop` ถูกนำไปใช้ตอนสร้างรายงานโดยอัตโนมัติ
- **ห้ามรัน match_claims.py ซ้ำหลังได้ verify.csv** (ผล `pass` อ้างผลชุดเดิม) ถ้าต้องแก้ FACTS ให้เทียบว่าผลข้อไหนเปลี่ยน แล้วส่งเฉพาะข้อนั้นตรวจใหม่
- สิ่งที่ด่านตรวจเจอเพิ่ม (แถว `U*` ใน verify.csv เช่น ลูกหนี้ค้างนานในหมายเหตุ) ให้ใส่ใน summary.md เอง และเพิ่มตัวเลขนั้นเข้า FACTS.csv พร้อมตำแหน่งในหมายเหตุ
- ชนเพดานการใช้งานกลางทาง: agent ที่หยุดไปทำต่อได้ด้วย SendMessage หลังเพดานรีเซ็ต ไม่ต้องเริ่มใหม่
- ถ้า `drop` เกิน 20% แปลว่าการเก็บคำพูดหละหลวม → ส่ง kep-lek ทำใหม่พร้อมเหตุผล แล้วกลับไปขั้น 4

### 5.5 ตรวจผู้บริหาร (ขนานกับขั้น 5 ได้)
อ่าน `reference/sectors/management.md` ก่อน แล้วเก็บหลักฐาน 2 ชุด
1. การซื้อขายหุ้นของผู้บริหาร (แบบ 59 ของ ก.ล.ต.):
   `python "$S/fetch_r59.py" T --vault V --from 01/01/<ปีก่อน ค.ศ.> --to <วันนี้ dd/mm/yyyy> --out W/insider_r59.csv`
   (หาชื่อบริษัทภาษาอังกฤษจากไฟล์ในคลังเอง · ไม่เจอ → `--name "<ชื่อตามรายชื่อ ก.ล.ต.>"`)
2. ผู้ถือหุ้นใหญ่ · ผู้ก่อตั้ง · CEO · เป้าใน 56-1 · รายการเกี่ยวโยง · ปันผล · ธุรกิจใหม่ → agent (sonnet) อ่าน `V/*_56-1_*.txt` ด้วย Grep
   เขียน `W/management_facts.md` (ทุกบรรทัดมี `[ที่มา: ไฟล์, หน้า]` · หาไม่เจอ = "ไม่พบใน 56-1")
- ดูจังหวะ: ผู้บริหารขายหุ้นหลัง Oppday/ประกาศเป้า = จดเป็นข้อสังเกต (ไม่สรุปเจตนา) · ไม่มีรายการ = เขียนว่า "ไม่มีรายงานแบบ 59 ในช่วงนี้"
- การซื้อขายของผู้บริหารเป็น **ข้อมูลประกอบ ไม่ใช่ตัวชี้ขาด** — ห้ามเขียน "สัญญาณมั่นใจ/สัญญาณเตือน" (คลิป EP.7 ผู้สอนยกทั้งกรณีขายแล้วหุ้นขึ้นต่อและขายแล้วหุ้นลง)
- ถ้ามีเป้าทั้งปี: เทียบยอดสะสมถึงงวดนี้กับสัดส่วนรายไตรมาสของปีก่อน (ปรับฤดูกาล) ก่อนสรุปว่าต้องเร่งแค่ไหน

### 6. เขียนบทสรุป `W/summary.md` (หน้าต่างหลักเขียนเอง)
หัวข้อ: `## บรรทัดเดียว` · `## สรุปงบ` · `## ผู้บริหารพูดตรงแค่ไหน` · `## ตรวจผู้บริหาร` · `## ต้องเชื่ออะไร` · `## เงื่อนไขเปลี่ยนใจ`
- `## ตรวจผู้บริหาร` ตอบ 7 ข้อท้าย `management.md` (พูดตรง · พูดเรื่องไม่ดีเองไหม · เป้ามีเหตุผลรองรับไหม · เป้าเก่าทำได้ไหม · ผู้ถือหุ้น/แบบ 59 · เปลี่ยนทีม/เจ้าของ · บรรทัดปิด "ยังไม่ได้ตรวจ") · คะแนนพูดตรง = ความตรงของคำพูดต่องบ ไม่ใช่การวัดความซื่อสัตย์ทั้งตัวคน
- ภาษาธุรกิจง่าย ๆ สรุปก่อน รายละเอียดทีหลัง (ผู้อ่าน = CEO)
- ตัวเลขทุกตัวมาจาก FACTS.csv / claims_checked.csv · ที่คิดเองกำกับ `[คำนวณ]` ในบรรทัดเดียวกัน
- พูดถึง "สิ่งที่ไม่ได้พูด" ทุกข้อที่ `said = n`

### 8. หน้าเทียบกลุ่ม (สั่ง ≥ 2 ตัวที่ทำธุรกิจเดียวกัน)
